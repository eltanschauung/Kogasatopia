# Retired Weapons service providers

FOV and Sentry control now live in Weapons / `weapons_ext`. These originals are
historical sources, not compatible optional companions to the merged system.
Do not compile or deploy them beside Weapons.

The other listed providers were installed third-party binaries, not existing
source files in this repository. Their upstream versions and licenses are
recorded in `extensions/weapons_ext/THIRD_PARTY.md`. Live originals are retained
recoverably under SourceMod's disabled plugin directory during deployment.
